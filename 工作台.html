使用说明与交付

怎么用这个工位

  1. 把想要的功能直接说给 AI，不用先写文档。
  2. 点上面的页面看原型，把不满意的地方告诉 AI。
  3. 每次改完让 AI「刷新工作台」，它会自己检查两边是否一致；顶部会显示检查结果。

不需要 git，不需要命令行，也不需要懂代码。不要自己改这个页面。

常用说法：「我有个想法……先问我几个关键问题」「把首页改简单点」「帮我评审，看看哪里不一致」。

给 AI 的开场白 
你是我的产品搭档。先读 AGENTS.md、STATE.md 和 product/PRD.md，用一句话告诉我现在做到哪、下一步做什么。
然后按我说的改。改完自己运行 npm run sync 和 npm run check，刷新工作台，再告诉我：改了哪些需求、哪些页面、还有什么没定。
不要要求我运行命令，也不要让我碰 git。

要发给研发？

不要发整个工作区。对 AI 说「导出交付包」，它会生成只含 PRD 和原型的 zip。

产物在 dist/ 下：同名文件夹 + 同名 .zip。
