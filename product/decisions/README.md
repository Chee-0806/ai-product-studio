# 决策记录（ADR）

一次决策一个文件，命名 `NNNN-短标题.md`。

规则：

- **只增不改**：决策被推翻时，新写一条，并在旧文件顶部标 `状态: superseded by NNNN`。
- 写清「选了什么、为什么、否掉了什么、代价是什么」。
- PRD 只链接决策，不复述理由；实现细节以 PRD 与原型为准。
- 编号连续，不复用。
- 最后一节固定写「被否决的方案与原因」：负面知识只有这一个落点，工位的承诺账本从这里读。允许一句话一条，不写也没人逼你——但那条否决就会跟着对话一起消失。

模板：

```md
# NNNN 决策标题

- 日期：YYYY-MM-DD
- 状态：accepted | superseded by NNNN
- 关联需求：REQ-00x

## 背景
## 决策
## 取舍
## 被否决的方案与原因

- 方案 A：否决原因
- 方案 B：否决原因
```
